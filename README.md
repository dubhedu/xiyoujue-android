# 西游·字决

《西游·字决》是一款以西游为题材、以汉字玩法为核心的休闲益智游戏。玩家在取经路上通过拼字、组字破解关卡，边玩边重温汉字之美。

## 玩法特色

- **汉字拼组**：将散落的字根组合成完整汉字，应对沿途妖魔鬼怪
- **西游剧情**：以唐僧师徒西行取经为主线，逐关解锁剧情与角色
- **轻量单机**：无需联网即可游玩，适合碎片时间体验
